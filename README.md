# HomeFlow

Εφαρμογή για Windows και Mac για τα έσοδα και τα έξοδα του σπιτιού. Αντικαθιστά το παλιό Excel.

## Εγκατάσταση σε Windows (μία φορά)

1. Ανοίξτε την [τελευταία έκδοση για Windows](https://github.com/demelistasos/HomeFlow/releases/latest) και κατεβάστε το `HomeFlow-Setup-….exe`.
2. Διπλό κλικ. Αν τα Windows πουν «Τα Windows προστάτευσαν τον υπολογιστή σας», πατήστε **Περισσότερες πληροφορίες → Εκτέλεση οπωσδήποτε**. Αυτό εμφανίζεται επειδή η εφαρμογή δεν έχει ψηφιακή υπογραφή.
3. Η εφαρμογή ανοίγει μόνη της και βάζει εικονίδιο στην επιφάνεια εργασίας.
4. Την πρώτη φορά πατήστε **«Άνοιγμα αρχείου HomeFlow»** και διαλέξτε το `homeflow-data.json` με τα στοιχεία από το Excel.

## Εγκατάσταση σε Mac

1. Στα [Releases](https://github.com/demelistasos/HomeFlow/releases) βρείτε την πιο πρόσφατη έκδοση **«για Mac»** και κατεβάστε το `HomeFlow-…-mac.dmg`. Δουλεύει και σε Apple Silicon και σε Intel.
2. Ανοίξτε το και σύρετε το **HomeFlow** στον φάκελο **Εφαρμογές**.
3. Την πρώτη φορά το Mac θα πει ότι δεν μπορεί να επαληθεύσει την εφαρμογή, επειδή δεν έχει υπογραφή Apple. Πατήστε **Τέλος** και μετά:
   **Ρυθμίσεις συστήματος → Απόρρητο και ασφάλεια →** κάτω κάτω **«Άνοιγμα ούτως ή άλλως»**.
   Αν πει ότι η εφαρμογή «είναι κατεστραμμένη», ανοίξτε το Τερματικό και γράψτε:
   `xattr -cr /Applications/HomeFlow.app`
4. Στο Mac οι νέες εκδόσεις δεν μπαίνουν μόνες τους. Η εφαρμογή δείχνει ειδοποίηση «Υπάρχει νέα έκδοση» με κουμπί «Κατέβασμα».

Τα δεδομένα είναι στο `Έγγραφα/HomeFlow/` και το ίδιο αρχείο ανοίγει και στα Windows.

## Ενημερώσεις

Κάθε αλλαγή στο `main` φτιάχνει αυτόματα δύο χωριστές εκδόσεις στα Releases: `v0.1.N` για Windows και `mac-v0.1.N` για Mac.
Η εφαρμογή ελέγχει όταν ανοίγει, κατεβάζει τη νέα έκδοση και την εγκαθιστά στο επόμενο κλείσιμο. Υπάρχει και κουμπί «Επανεκκίνηση τώρα».

## Πού είναι τα δεδομένα

- Αρχείο: `Έγγραφα\HomeFlow\homeflow-data.json`. Ο φάκελος αλλάζει από τις Ρυθμίσεις, π.χ. σε OneDrive.
- Κάθε μέρα κρατιέται αντίγραφο στον φάκελο `Αντίγραφα ασφαλείας`, και μένουν τα τελευταία 60.
- Τα δεδομένα **δεν** ανεβαίνουν ποτέ στο GitHub. Το repository έχει μόνο τον κώδικα.

## Για προγραμματιστές

```
npm install
npm start        # τρέχει την εφαρμογή
npm run dist     # φτιάχνει τον installer τοπικά (dist/)
```

- `main.js`: παράθυρο, αποθήκευση αρχείου, αντίγραφα, αυτόματες ενημερώσεις
- `preload.js`: η γέφυρα ανάμεσα στο παράθυρο και τον υπολογιστή
- `renderer/`: η εφαρμογή (HTML/CSS/JS, χωρίς βιβλιοθήκες). Ανοίγει και σε απλό browser για δοκιμές, με αποθήκευση στο localStorage.
