# HomeFlow

Εφαρμογή για Windows και Mac για τα έσοδα και τα έξοδα του σπιτιού. Αντικαθιστά το παλιό Excel.

## Ποιο αρχείο κατεβάζω

Ανοίξτε την [τελευταία έκδοση](https://github.com/demelistasos/HomeFlow/releases/latest). Έχει δύο αρχεία:

| Υπολογιστής | Αρχείο |
|---|---|
| **Windows** | `HomeFlow-Windows-0.1.N.zip` |
| **Mac** | `HomeFlow-Mac-0.1.N.zip` |

## Windows

1. Αποσυμπιέστε το zip (δεξί κλικ → «Εξαγωγή όλων…»), π.χ. στα Έγγραφα.
2. Διπλό κλικ στο **HomeFlow.exe**. Αν τα Windows πουν «Τα Windows προστάτευσαν τον υπολογιστή σας», πατήστε **Περισσότερες πληροφορίες → Εκτέλεση οπωσδήποτε**.
3. Για εικονίδιο στην επιφάνεια εργασίας: δεξί κλικ στο HomeFlow.exe → **Αποστολή προς → Επιφάνεια εργασίας**.

## Mac

1. Ανοίξτε το zip και σύρετε το **HomeFlow** στις **Εφαρμογές**.
2. Την πρώτη φορά το Mac θα πει ότι δεν μπορεί να επαληθεύσει την εφαρμογή. Πατήστε **Τέλος** και μετά **Ρυθμίσεις συστήματος → Απόρρητο και ασφάλεια →** κάτω κάτω **«Άνοιγμα ούτως ή άλλως»**.
   Αν πει ότι είναι «κατεστραμμένη», στο Τερματικό γράψτε: `xattr -cr /Applications/HomeFlow.app`

## Πρώτη φορά

Πατήστε **«Άνοιγμα αρχείου HomeFlow»** και διαλέξτε το `homeflow-data.json` με τα στοιχεία από το Excel.

## Νέες εκδόσεις

Όταν βγαίνει νέα έκδοση, το HomeFlow δείχνει πάνω πάνω **«Υπάρχει νέα έκδοση»**. Με **«Ενημέρωση τώρα»** κατεβάζει το σωστό zip, ελέγχει το αποτύπωμά του (`SHA256SUMS.txt`), κλείνει και ξανανοίγει στη νέα έκδοση. Πριν από κάθε ενημέρωση κρατάει αντίγραφο των δεδομένων. Δεν γίνεται τίποτα χωρίς ερώτηση.
Στα Windows ο φάκελος του HomeFlow πρέπει να είναι κάπου που επιτρέπει αλλαγές (π.χ. Έγγραφα), όχι στο «Program Files». Αλλιώς η εφαρμογή δείχνει το κουμπί «Κατέβασμα» για ενημέρωση με το χέρι.
**Τα στοιχεία δεν χάνονται**, γιατί δεν βρίσκονται μέσα στον φάκελο της εφαρμογής.

## Πού είναι τα δεδομένα

- `Έγγραφα/HomeFlow/homeflow-data.json`. Ο φάκελος αλλάζει από τις Ρυθμίσεις, π.χ. σε OneDrive. Το ίδιο αρχείο ανοίγει και σε Windows και σε Mac.
- Κάθε μέρα κρατιέται αντίγραφο στον φάκελο `Αντίγραφα ασφαλείας`, και μένουν τα τελευταία 60.
- Τα δεδομένα **δεν** ανεβαίνουν ποτέ στο GitHub. Το repository έχει μόνο τον κώδικα.

## Για προγραμματιστές

Κάθε αλλαγή στο `main` φτιάχνει αυτόματα (GitHub Actions) μία έκδοση `v0.1.N` με ένα zip για Windows και ένα για Mac.

```
npm install
npm start        # τρέχει την εφαρμογή
npm run dist     # φτιάχνει το zip τοπικά (dist/)
```

### Οργάνωση των αρχείων

```
main.js            παράθυρο, αποθήκευση, αντίγραφα (cloud/USB), συνημμένα, Excel, ενημέρωση
updater.js         ενημέρωση μέσα από την εφαρμογή (κατέβασμα, έλεγχος SHA-256, αντικατάσταση)
xlsx.js            δημιουργία αρχείων Excel χωρίς βιβλιοθήκες
preload.js         η γέφυρα ανάμεσα στο παράθυρο και τον υπολογιστή
renderer/
  index.html       φορτώνει τα παρακάτω ΜΕ ΑΥΤΗ ΤΗ ΣΕΙΡΑ
  css/1…6-*.css    εμφάνιση: χρώματα (φωτεινή/σκούρα) → διάταξη → στοιχεία → εκτύπωση → λειτουργίες → προσαρμογή οθόνης
  js/core.js       σταθερές, βοηθητικά, αποθήκευση
  js/model.js      λογική δεδομένων (πάγια, ενοίκια, ερωτήματα)
  js/render.js     κεντρικό σχεδίασμα σελίδας
  js/pages/*.js    μία σελίδα ανά αρχείο (home, list, rent, money, tax, …)
  js/dialogs/*.js  τα παράθυρα
  js/features/*.js PIN, αντίγραφα, ημερολόγιο, ασφάλειες, συνημμένα, βοήθεια, αναζήτηση, Excel, ενημέρωση
  js/form.js       φόρμα καταχώρησης
  js/actions.js    τι κάνει κάθε κουμπί (data-action)
  js/events.js     κλικ, πληκτρολόγιο, αλλαγές πεδίων
  js/init.js       εκκίνηση
tests/
  fixture.js       ψεύτικα δεδομένα δοκιμής (ΠΟΤΕ πραγματικά)
  unit.test.js     δοκιμές για ενημέρωση και Excel
  ui.test.js       ανοίγει κάθε σελίδα και καρτέλα σε 3 μεγέθη, φωτεινή και σκούρα, και κάνει τις βασικές ενέργειες
```

Τα αρχεία JS είναι απλά scripts (όχι modules) και μοιράζονται τις ίδιες μεταβλητές, γι' αυτό **η σειρά στο index.html μετράει**.

```
npm test         # τρέχει όλες τις δοκιμές (χρειάζεται playwright)
```

Στο GitHub οι δοκιμές τρέχουν πριν από κάθε έκδοση· αν αποτύχει έστω και μία, δεν βγαίνει νέα έκδοση.
